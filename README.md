## 杏花云(XingHua)VPN套餐与使用常见问题

### 最低多少钱，50GB 是全年流量吗？

最低年付为 **¥12/年、每月 50GB**，折合 **¥1/月**，并非全年总共只有 50GB。按月购买可选 **¥3/月、200GB/月**的轻量版，以上均为使用优惠码前的标价。

<a id="xinghua-billing-periods"></a>

### 季付和年付价格怎么算？

轻量版、标准版和专业版的季付价格分别为 **¥9、¥18、¥30**，即各自月价的 3 倍；年付分别为 **¥36、¥72、¥120**，即各自月价的 12 倍。年付-50G 与年付-100G 是另外两档方案，分别为 ¥12/年和 ¥24/年。

<a id="xinghua-one-time-validity"></a>

### 1000GB 一次性流量包可以用多久？

一次支付 **¥20** 获得 **1000GB 总流量**，有效期为 **365 天**，用完或到期即止。它与专业版的每月 1000GB 不同：专业版按月提供流量，一次性套餐则在有效期内共用固定额度。

### 支持哪些客户端和支付方式？
